# Инструкция по деплою на Beget

## Шаги для деплоя:

### 1. Соберите проект локально
```bash
npm run build
```

После выполнения команды появится папка `dist` с готовыми файлами.

### 2. Загрузите файлы на хостинг

**ВАЖНО:** Загружайте на Beget только содержимое папки `dist`, а не весь проект!

Через FTP/SFTP загрузите все файлы из папки `dist` в корневую директорию вашего сайта (обычно это `public_html` или `www`).

### 3. Структура файлов на сервере должна быть:

```
public_html/
├── index.html
├── assets/
│   ├── index-[hash].js
│   ├── index-[hash].css
│   └── ...
└── images/
    └── ...
```

### 4. Проверьте права доступа

Убедитесь, что файлы имеют правильные права:
- Файлы: 644
- Папки: 755

## Частые ошибки:

❌ **НЕ загружайте:**
- Папку `src`
- Папку `node_modules`
- Файлы `package.json`, `vite.config.ts` и т.д.

✅ **Загружайте только:**
- Содержимое папки `dist`

## Обновление сайта:

При каждом изменении:
1. Запустите `npm run build`
2. Загрузите обновленные файлы из `dist` на сервер
