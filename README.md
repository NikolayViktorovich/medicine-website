# Твой-ЛОР Врач - Камынина Анастасия Викторовна

Современный медицинский сайт-визитка врача-оториноларинголога с плавной анимацией и адаптивным дизайном. Сайт предоставляет информацию о враче, услугах и возможность записи на онлайн и очный приём.

## Live Demo

[Посмотреть Демо](https://medicine-website-ten.vercel.app/) 

## Основные функции

- Главная страница с информацией о враче и анимированными элементами
- Раздел "О враче" с образованием и опытом работы
- Каталог услуг - заболевания ЛОР-органов
- Информация об онлайн-консультациях
- Информация об очном приёме
- Раздел с ответами на частые вопросы
- Контактная информация и форма записи
- Плавные анимации и современный дизайн

## Ключевые технологии

- **Frontend:** React 19 + TypeScript
- **Сборка:** Vite 7
- **Стили:** CSS Modules
- **Линтинг:** ESLint 9

## Установка и Запуск

1. Клонируйте репозиторий:
```bash
git clone [URL репозитория]
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите dev-сервер:
```bash
npm run dev
```

4. Сборка для продакшена:
```bash
npm run build
```

5. Предпросмотр продакшен-сборки:
```bash
npm run preview
```
